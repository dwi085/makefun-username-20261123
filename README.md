# One Word, One Username, One Reward

Entry for the [make.fun bounty "One Word, One Username, One Reward"](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae).

The program writes exactly one word — the entrant's own make.fun username, `savira1636` — to `/output/entry.txt`, and nothing else: no explanation, no links, no pitch, no extra newline. Deterministic: two runs produce byte-identical output.
